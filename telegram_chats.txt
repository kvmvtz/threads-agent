# Список Telegram-чатов/каналов для мониторинга ботом.
#
# Формат: один чат на строку — username без @ (например my_chat_name) или
# просто t.me-ссылка. Строки с # — комментарии, пустые строки пропускаются.
#
# ВАЖНО: бот читает только те чаты, в которые Telegram-аккаунт (тот, что
# логинили через scripts/telegram-login.js) УЖЕ вступил вручную. Сам бот
# никуда не вступает и ничего не ищет — это осознанно, чтобы не выглядеть
# для Telegram подозрительно (быстрое массовое вступление в чаты — то, за
# что банят автоматизацию).
#
# Список пока пуст — состав чатов подбираем отдельным шагом (нужен ресёрч,
# какие русскоязычные чаты/каналы реально дают лиды под нашу нишу).
